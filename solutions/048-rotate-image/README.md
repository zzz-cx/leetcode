# 48. 旋转图像

**难度：** 中等  
**标签：** 数组、数学、矩阵

> [rotate-image](https://leetcode.cn/problems/rotate-image/)

## 题目描述

给定一个 `n × n` 的二维矩阵 `matrix` 表示一个图像，请你**原地**将图像顺时针旋转 90 度。

你必须在**原地**旋转，即直接修改输入矩阵，不能使用另一个矩阵。

### 示例 1

```
输入: matrix = [[1,2,3],[4,5,6],[7,8,9]]
输出: [[7,4,1],[8,5,2],[9,6,3]]
```

```
原图:          顺时针 90° 后:
1  2  3        7  4  1
4  5  6   →    8  5  2
7  8  9        9  6  3
```

### 示例 2

```
输入: matrix = [[5,1,9,11],[2,4,8,10],[13,3,6,7],[15,14,12,16]]
输出: [[15,13,2,5],[14,3,4,1],[12,6,8,9],[16,7,10,11]]
```

### 提示

- `n == matrix.length == matrix[i].length`
- `1 <= n <= 20`
- `-1000 <= matrix[i][j] <= 1000`

## 思路说明

### 旋转的坐标规律

顺时针旋转 90° 后，原位置 `(r, c)` 的元素会移动到 `(c, n - 1 - r)`：

```
(r, c)  ──顺时针90°──→  (c, n-1-r)
```

以 3×3 为例（`n = 3`）：

| 原坐标 | 新坐标 | 元素 |
|:------:|:------:|:----:|
| (0,0) | (0,2) | 1 → 右上 |
| (0,2) | (2,2) | 3 → 右下 |
| (2,2) | (2,0) | 9 → 左下 |
| (2,0) | (0,0) | 7 → 左上 |

四个角上的元素形成一个**循环**：

```
        (i, j) ─────────→ (j, n-i-1)
           ↑                    │
           │                    ↓
    (n-j-1, i) ←─────── (n-i-1, n-j-1)
```

### 核心操作：四元素循环交换

一次交换让 4 个位置上的值沿顺时针方向各走一步：

```
tmp = a
a = d    // 左下 → 左上
d = c    // 右下 → 左下
c = b    // 右上 → 右下
b = tmp  // 左上 → 右上
```

对应代码中的四个下标（以 `(i, j)` 为起点）：

| 位置 | 下标 | 在环上的角色 |
|------|------|--------------|
| 左上 | `(i, j)` | a |
| 右上 | `(j, n-i-1)` | b |
| 右下 | `(n-i-1, n-j-1)` | c |
| 左下 | `(n-j-1, i)` | d |

```go
matrix[i][j], matrix[j][n-i-1], matrix[n-i-1][n-j-1], matrix[n-j-1][i] =
    matrix[n-j-1][i], matrix[i][j], matrix[j][n-i-1], matrix[n-i-1][n-j-1]
```

赋值顺序是**逆时针写入**（d→a, a→b, b→c, c→d），等价于四个值顺时针轮转。

### 3×3 完整演示

初始矩阵，以 `(i,j)=(0,0)` 为例：

```
环 1: (0,0)=1  (0,2)=3  (2,2)=9  (2,0)=7

步骤:  1  2  3       7  2  1       7  2  1       7  2  3
       4  5  6  →    4  5  6  →    4  5  6  →    4  5  6
       7  8  9       7  8  9       9  8  9       9  8  7
       初始           交换后1        交换后2        交换后3(完成)
```

再处理 `(i,j)=(0,1)` 的环：`2 → 6 → 8 → 4`，最终得到：

```
7  4  1
8  5  2
9  6  3
```

中心 `(1,1)` 在 `n=3` 时旋转前后不变，无需交换。

### 循环范围：为什么 i 和 j 这样写

```go
for i := 0; i < n/2; i++ {          // 只处理上半个「环带」
    for j := i; j < n-i-1; j++ {    // 每环带上从左到右，不含右边界
```

把矩阵想成一圈套一圈的**同心方框**：

```
n = 4 时，i 取 0 和 1 两层:

i=0 层（最外圈）:          i=1 层（内圈）:
┌─────────────┐            ┌───┐
│ → → → ↓     │            │5 6│  只交换 5↔6↔7↔8
│ ↑       ↓   │            │8 7│
│ ↑       ↓   │            └───┘
│ ← ← ← ←     │
└─────────────┘
 j: 0,1,2        j: 1（仅 1 个）
```

| 变量 | 范围 | 含义 |
|------|------|------|
| `i` | `0 .. n/2 - 1` | 第几层方框（从外到内） |
| `j` | `i .. n-i-2` | 该层上边从左到右的每个起点 |

- **`i < n/2`**：n 为奇数时，最中心一层只有一个元素，旋转不变，不需要处理。
- **`j < n-i-1`**：每层四个角不能重复交换，上边只走到右上角前一个位置。
- 每层共 `n - 2i - 1` 次四元素交换，所有层加起来恰好 `n²/4` 次（每个元素参与一次环交换）。

### 方法二：转置 + 逐行反转（对比）

另一种常见写法，逻辑更直观：

```
顺时针 90° = 先转置矩阵，再每行左右反转
```

```python
# 转置: matrix[r][c] ↔ matrix[c][r]
for r in range(n):
    for c in range(r + 1, n):
        matrix[r][c], matrix[c][r] = matrix[c][r], matrix[r][c]
# 每行反转
for row in matrix:
    row.reverse()
```

| 方法 | 优点 | 缺点 |
|------|------|------|
| 四元素环交换 | 一次遍历、无额外步骤 | 下标难记 |
| 转置 + 反转 | 思路清晰、易写 | 两步操作 |

两种方法都是 **O(n²) 时间、O(1) 额外空间**。

### 复杂度

- **时间：** O(n²) — 每个元素恰好移动一次
- **空间：** O(1) — 原地修改

## 解答

### Python

文件：[solution.py](./solution.py)

```python
class Solution:
    def rotate(self, matrix: List[List[int]]) -> None:
        n = len(matrix)
        for i in range(n // 2):
            for j in range(i, n - i - 1):
                (
                    matrix[i][j],
                    matrix[j][n - i - 1],
                    matrix[n - i - 1][n - j - 1],
                    matrix[n - j - 1][i],
                ) = (
                    matrix[n - j - 1][i],
                    matrix[i][j],
                    matrix[j][n - i - 1],
                    matrix[n - i - 1][n - j - 1],
                )
```

**代码解析**

- **`range(n // 2)`** — 从外到内处理每一层方框。
- **`range(i, n - i - 1)`** — 当前层上边的每个起点 `(i, j)`。
- **四元组赋值** — Python 同时求值再赋值，避免覆盖中间值。

### Golang

文件：[solution.go](./solution.go)

```go
func rotate(matrix [][]int) {
    n := len(matrix)
    for i := 0; i < n/2; i++ {
        for j := i; j < n-i-1; j++ {
            matrix[i][j], matrix[j][n-i-1], matrix[n-i-1][n-j-1], matrix[n-j-1][i] =
                matrix[n-j-1][i], matrix[i][j], matrix[j][n-i-1], matrix[n-i-1][n-j-1]
        }
    }
}
```

**代码解析**

- Go 的多重赋值同样支持并行求值，一行完成四元素轮转。
- **`n-i-1`** — 第 `i` 层对应的下边/右边坐标（与第 `i` 层对称）。
