# 36. 有效的数独

**难度：** 中等  
**标签：** 数组、哈希表、矩阵

> [valid-sudoku](https://leetcode.cn/problems/valid-sudoku/)

## 题目描述

请你判断一个 9×9 的数独是否有效。只需根据以下规则，验证**已经填入**的数字是否有效即可：

1. 数字 `1-9` 在每一行只能出现一次
2. 数字 `1-9` 在每一列只能出现一次
3. 数字 `1-9` 在每一个 3×3 宫内只能出现一次

### 注意

- 一个有效的数独（部分已被填充）**不一定是可解的**
- 只需验证已填数字是否违反规则
- 空白格用 `'.'` 表示

### 示例 1

```
输入:
board =
[["5","3",".",".","7",".",".",".","."]
,["6",".",".","1","9","5",".",".","."]
,[".","9","8",".",".",".",".","6","."]
,["8",".",".",".","6",".",".",".","3"]
,["4",".",".","8",".","3",".",".","1"]
,["7",".",".",".","2",".",".",".","6"]
,[".","6",".",".",".",".","2","8","."]
,[".",".",".","4","1","9",".",".","5"]
,[".",".",".",".","8",".",".","7","9"]]
输出: true
```

### 示例 2

```
输入:
board =
[["8","3",".",".","7",".",".",".","."]
,["6",".",".","1","9","5",".",".","."]
,[".","9","8",".",".",".",".","6","."]
,["8",".",".",".","6",".",".",".","3"]
,["4",".",".","8",".","3",".",".","1"]
,["7",".",".",".","2",".",".",".","6"]
,[".","6",".",".",".",".","2","8","."]
,[".",".",".","4","1","9",".",".","5"]
,[".",".",".",".","8",".",".","7","9"]]
输出: false
```

解释：第一行中有两个 `8`（与第一列的 `8` 无关，行内重复即无效）。

### 提示

- `board.length == 9`
- `board[i].length == 9`
- `board[i][j]` 是 `'1'`~`'9'` 或 `'.'`

## 思路说明

### 问题转化

遍历每个已填格子 `(r, c)`，检查数字 `board[r][c]` 是否在以下三个维度上**重复出现**：

| 维度 | 索引 |
|------|------|
| 行 | `r` |
| 列 | `c` |
| 3×3 宫 | `box = (r // 3) * 3 + (c // 3)` |

```
宫格编号（box index）:
┌───┬───┬───┐
│ 0 │ 1 │ 2 │
├───┼───┼───┤
│ 3 │ 4 │ 5 │
├───┼───┼───┤
│ 6 │ 7 │ 8 │
└───┴───┴───┘
```

### 哈希集合 / 布尔数组

维护三组「已出现数字」记录：

- `rows[r]` — 第 `r` 行已出现的数字
- `cols[c]` — 第 `c` 列已出现的数字
- `boxes[box]` — 第 `box` 宫已出现的数字

遇到 `'.'` 跳过；否则若数字已在任一组中出现，返回 `false`；否则加入三组。

### 算法流程图

```
开始
  ↓
初始化 rows, cols, boxes
  ↓
遍历 r = 0..8, c = 0..8
  ↓
board[r][c] == '.' ? → 是 → 继续
  ↓ 否
计算 box = (r/3)*3 + (c/3)
  ↓
数字已在 rows[r] / cols[c] / boxes[box] 中？ → 是 → 返回 false
  ↓ 否
加入三组集合
  ↓
全部通过 → 返回 true
```

### 复杂度

- **时间：** O(1) — 固定 9×9 = 81 格
- **空间：** O(1) — 最多 9×9×3 个标记

## 解答

### Python

文件：[solution.py](./solution.py)

```python
class Solution:
    def is_valid_sudoku(self, board: List[List[str]]) -> bool:
        rows: list[set[str]] = [set() for _ in range(9)]
        cols: list[set[str]] = [set() for _ in range(9)]
        boxes: list[set[str]] = [set() for _ in range(9)]

        for r in range(9):
            for c in range(9):
                ch = board[r][c]
                if ch == ".":
                    continue
                box = (r // 3) * 3 + c // 3
                if ch in rows[r] or ch in cols[c] or ch in boxes[box]:
                    return False
                rows[r].add(ch)
                cols[c].add(ch)
                boxes[box].add(ch)

        return True
```

**代码解析**

- **`box = (r // 3) * 3 + c // 3`** — 将 9×9 坐标映射到 9 个宫格之一。
- **三组 `set`** — 分别追踪行、列、宫的已用数字。
- **跳过 `'.'`** — 空格不参与冲突检测。

### Golang

文件：[solution.go](./solution.go)

```go
func isValidSudoku(board [][]byte) bool {
    var rows, cols, boxes [9][9]bool

    for r := 0; r < 9; r++ {
        for c := 0; c < 9; c++ {
            if board[r][c] == '.' {
                continue
            }
            digit := board[r][c] - '1'
            box := (r/3)*3 + c/3
            if rows[r][digit] || cols[c][digit] || boxes[box][digit] {
                return false
            }
            rows[r][digit] = true
            cols[c][digit] = true
            boxes[box][digit] = true
        }
    }
    return true
}
```

**代码解析**

- **`[9][9]bool`** — 用布尔数组代替 set，数字 `'1'`~`'9'` 映射到下标 `0`~`8`。
- **`digit := board[r][c] - '1'`** — 字符转数字下标。
- **固定 O(1) 空间** — 9×9 棋盘规模恒定。
